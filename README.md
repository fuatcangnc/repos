# TuranCMS Starter Repositories

TuranCMS için hazırlanan Astro + Cloudflare başlangıç projeleri.

## Starter'lar

- `kurumsal/` — çok sayfalı kurumsal web sitesi starter'ı
- `hizmet/` — hizmet firmaları için web sitesi starter'ı

Her klasör kendi başına `npm install`, `npm run dev` ve `npm run build` ile
çalıştırılabilir. TuranCMS şablon kataloğu bu klasörleri kaynak olarak kullanır
ve seçilen starter'ı yeni GitHub reposuna temiz bir proje olarak aktarır.
